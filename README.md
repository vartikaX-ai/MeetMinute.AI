# 📝 Smart Meeting Minutes Generator (MeetMinute.AI)

AI-powered meeting minutes generation system that processes meeting audio recordings, identifies speakers, and automatically generates structured meeting documents with categorized discussion points and speaker-wise conversation flow.

---

## 🚀 Features

- Speech-to-text transcription using Whisper
- Speaker diarization using PyAnnote
- Speaker-wise conversation tracking
- AI-based discussion point classification
- Structured meeting minute generation
- Important discussion point extraction
- PDF meeting document generation
- Interactive web-based user interface

---

## 🛠️ Tech Stack

- Python
- Whisper
- PyAnnote
- Groq API (Llama)
- spaCy
- ReportLab
- NLP
- HTML
- CSS
- JavaScript

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/vartikaX-ai/meetminute-ai.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python webapp.py
```

---

## 🔑 Environment Variables

Create a `.env` file and add your API keys:

```env
SUPABASE_PASSWORD=your_password
SECRET_KEY=your_secret_key
GROQ_API_KEY=your_groq_api_key
HF_token=your_huggingface_token
```
